# Clima Alert

Prototipo académico de una aplicación Android para consultar el clima de Lima y mostrar recomendaciones preventivas ante lluvias intensas, inundaciones y huaicos.

## Generar el APK desde GitHub
1. Sube todos los archivos y carpetas de este proyecto a un repositorio nuevo.
2. Abre la pestaña **Actions**.
3. Selecciona **Construir APK de Clima Alert**.
4. Pulsa **Run workflow** y confirma.
5. Cuando termine correctamente, abre la ejecución y descarga el artefacto **ClimaAlert-APK**.

## Importante
- La consulta meteorológica usa la API pública de Open-Meteo.
- La ubicación de este prototipo está fijada en Lima.
- Las recomendaciones son informativas. Esta versión no recibe alertas oficiales de SENAMHI o INDECI, no detecta huaicos/inundaciones y no envía notificaciones push.
- Ante una emergencia, consulta los canales oficiales de las autoridades.
